# M08 — Results & Rewards

## Goal
Produce a trustworthy end-of-run result.

## Scope
- stage reached
- boss defeated
- accuracy
- difficulty attempted/correct counts
- remaining HP
- gold formula
- server-side reward calculation
- result UI

## Acceptance criteria
- client cannot set gold
- failed and successful runs both summarize correctly
- reward formula is documented
- duplicate finalization cannot duplicate gold

## Stop condition
Stop for review.
