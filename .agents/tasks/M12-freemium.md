# M12 — Freemium Gate

## Goal
Enforce the initial business rule without overbuilding billing.

## Scope
- one free dungeon/material generation
- additional generation gated
- entitlement state
- clear upgrade/paywall
- manual/test unlock if needed for BIFEST

## Do not build
Full production billing unless explicitly requested.

## Acceptance criteria
- free allowance works
- client cannot reset allowance
- paid/test entitlement unlocks more generation
- blocked state is clearly explained

## Stop condition
Stop for business-validation review.
