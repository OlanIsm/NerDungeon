# M05 — Single-Battle Combat Prototype

## Goal
Validate the Nerdungeon combat loop with one enemy.

## Scope
- Phaser battle scene
- one player
- one enemy
- HP visualization
- React/HTML question panel
- Easy/Medium/Hard
- 10/20/30 damage
- correct → enemy damage
- wrong → player damage
- basic feedback animation
- mobile portrait layout

## Do not build
- three stages
- boss mechanics
- rewards
- inventory
- gacha

## Acceptance criteria
- playable on phone browser
- question UI remains readable
- risk/reward is obvious
- no duplicate answer submission
- answer correctness is authoritative
- animations do not break flow

## Stop condition
Stop and ask the human whether the combat actually feels fun.
