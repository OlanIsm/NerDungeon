# M00 — Project Foundation

## Goal
Create the smallest deployable Nerdungeon foundation.

## Scope
- Next.js + TypeScript
- Tailwind
- mobile-first global layout
- Supabase env/config skeleton
- server/client Supabase helpers
- placeholder home/dashboard routes
- lint/typecheck/build scripts
- `.env.example`
- basic README run instructions

## Do not build
- auth
- upload
- AI
- dungeon
- domain tables
- payments

## Acceptance criteria
- app runs locally
- build succeeds
- no secrets committed
- mobile width has no horizontal overflow
- env vars documented
- deployment-ready baseline

## Stop condition
Stop after verification and wait for review.
