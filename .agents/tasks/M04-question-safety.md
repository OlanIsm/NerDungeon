# M04 — Report & Regenerate

## Goal
A user can flag one bad question and replace it safely.

## Scope
- report reasons
- optional note
- regenerate one question
- preserve difficulty
- same source material
- validation before replacement

## Acceptance criteria
- report is persisted
- owner-only access
- replacement keeps difficulty
- exactly 3 choices
- failed regeneration does not destroy current question

## Stop condition
Stop for review.
