# M06 — Three-Stage Dungeon

## Goal
Build the complete run structure.

## Scope
- Stage 1: one enemy
- Stage 2: two enemies
- Stage 3: boss
- persistent player HP
- stage transitions
- fail state
- completion state
- restart from Stage 1

## Do not build
- special boss mechanics
- advanced enemy abilities
- gacha

## Acceptance criteria
- HP never resets between stages
- death ends the run
- completion ends the run
- restart creates a clean run

## Stop condition
Stop for review.
