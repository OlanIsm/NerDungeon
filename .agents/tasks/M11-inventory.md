# M11 — Basic Inventory

## Goal
Validate one small RPG progression layer.

## Scope
Implement only 1–2 items:
- healing potion
- shield

Includes:
- inventory record
- use-item action
- quantity decrement
- server validation
- combat integration

## Do not build
- gacha
- cosmetic store
- large item catalog

## Acceptance criteria
- cannot use unowned item
- cannot reuse consumed item
- effect is authoritative
- state survives refresh appropriately

## Stop condition
Stop for review.
