# M01 — Authentication

## Goal
A user can authenticate and access a protected dashboard.

## Scope
- Supabase Auth
- one MVP sign-in method
- session-aware routing
- protected dashboard
- sign out

## Do not build
- materials
- questions
- game
- subscription

## Acceptance criteria
- unauthenticated user cannot access dashboard
- authenticated user can
- session survives refresh
- sign out works
- server can resolve current user
- mobile UI works

## Stop condition
Stop after tests/manual-check instructions.
