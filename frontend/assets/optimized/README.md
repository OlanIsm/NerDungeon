# Optimized UI artwork

These are resized WebP derivatives of existing repository artwork. No artwork was generated or sourced externally. Originals remain unchanged.

| Derivative | Original | Dimensions |
| --- | --- | --- |
| desert.webp | ../map/dessert.png | 640 x 426 |
| volcano.webp | ../map/volcano.png | 640 x 426 |
| kingdom.webp | ../map/kingdom.png | 640 x 426 |
| scholar.webp | ../character/mc.png | 384 x 384 |
| nerdius-title.webp | ../nerdius_title.png | 640 x 382 |

Conversion uses ffmpeg, Lanczos scaling, libwebp quality 82, and original alpha. Region art renders at up to 330 CSS pixels; the character renders at up to 192 CSS pixels. No frames, buttons or other UI geometry are rasterized.
